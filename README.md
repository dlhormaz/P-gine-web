# Plantilla de E-commerce para Shopify

Una plantilla moderna y completa para crear tiendas online en Shopify con todas las funcionalidades esenciales.

## 🎯 Características

- ✅ Diseño responsive y mobile-first
- ✅ Página de inicio con hero banner
- ✅ Catálogo de productos con filtros
- ✅ Carrito de compras funcional
- ✅ Sistema de búsqueda
- ✅ Integración de newsletter
- ✅ Página de producto detallada
- ✅ Reseñas y calificaciones
- ✅ Menú de navegación
- ✅ Pie de página con links

## 📁 Estructura del Proyecto

```
├── assets/                 # CSS y JavaScript
│   ├── styles.css         # Estilos principales
│   └── script.js          # Scripts funcionales
├── sections/              # Componentes Liquid reutilizables
│   ├── header.liquid      # Encabezado
│   └── footer.liquid      # Pie de página
├── snippets/              # Fragmentos de código
│   └── product-card.liquid # Tarjeta de producto
├── templates/             # Plantillas JSON
│   ├── index.json         # Página de inicio
│   ├── product.json       # Página de producto
│   └── collection.json    # Página de colección
├── config/                # Configuración
│   └── settings_schema.json # Parámetros personalizables
├── locales/               # Traducciones
│   └── es.json           # Español
└── package.json           # Dependencias
```

## 🚀 Instalación

1. Clona este repositorio
2. Instala las dependencias: `npm install`
3. Conecta tu tienda Shopify
4. Sigue la guía de instalación completa en `GUIA_INSTALACION.md`
